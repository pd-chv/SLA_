# ЧТО ТАКОЕ SLA?

**SLA (Service Level Agreement)** — это соглашение об уровне обслуживания, документ, который определяет стандарты качества услуг, предоставляемых поставщиком клиенту. В нем фиксируются:
- Показатели доступности сервиса
- Время реакции на обращения
- Время решения проблем
- Ответственность сторон
- Штрафные санкции за невыполнение обязательств

SLA помогает обеспечить прозрачность взаимоотношений между поставщиком услуг и заказчиком, устанавливая четкие ожидания и метрики качества обслуживания.

# ЧТО ТАКОЕ GITHUB?

**GitHub** — это веб-платформа для хостинга IT-проектов и их совместной разработки. Основные возможности:
- Хранение кода в репозиториях с использованием системы контроля версий Git
- Совместная работа над проектами
- Отслеживание изменений и ошибок
- Управление задачами и проектами
- Интеграция с различными инструментами разработки

GitHub является крупнейшим в мире хранилищем исходного кода и социальной сетью для разработчиков.
